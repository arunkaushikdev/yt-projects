# Counter App in React – Your First React Project

The classic first React project: a number with − / Reset / + buttons. The − button is disabled at 0, so the count never goes negative.

📺 **Video:** coming soon
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- `useState`
- `onClick` event handlers
- Updating state from the previous value: `setCount(prev => prev + 1)`
- Disabling a button with a condition

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/counter-app
npm install
npm run dev
```
Then open http://localhost:5173
