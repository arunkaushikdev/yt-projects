# Todo App in React – Part 1: Add, Edit & Delete (CRUD)

A beginner-friendly Todo App built with React + Vite.

📺 **Video:** https://youtu.be/Z3zK94cS-fo
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- `useState` and controlled inputs
- Adding, editing and deleting items (CRUD)
- Splitting UI into components with props
- Updating arrays immutably (spread, `map`, `filter`)

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/todo-app-part-1-crud
npm install
npm run dev
```
Then open http://localhost:5173
