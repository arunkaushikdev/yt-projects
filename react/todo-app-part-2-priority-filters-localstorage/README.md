# Advanced Todo App – Part 2: Priority, Filters & LocalStorage

Part 2 of the Todo series: adds priorities, complete/undo, filters and saving to LocalStorage. Starts from the Part 1 code.

📺 **Video:** https://youtu.be/XG7bUof6yJE
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- Priority levels and completed state
- Derived state for filters (All / Active / Completed)
- Saving and loading with `localStorage` + `useEffect`
- Lazy initial state: `useState(loadTasks)`

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/todo-app-part-2-priority-filters-localstorage
npm install
npm run dev
```
Then open http://localhost:5173
