# Weather App in React (Open-Meteo, no API key)

Search any city and see the current temperature, weather icon, humidity and wind, with a °C/°F toggle. Uses the free Open-Meteo API – no API key needed.

📺 **Video:** https://youtu.be/tGjUOwMkaxY
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- `fetch` with `async` / `await`
- Loading and error states ("City not found")
- Calling two APIs: geocoding → forecast
- Deploying free on Netlify

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/weather-app
npm install
npm run dev
```
Then open http://localhost:5173
