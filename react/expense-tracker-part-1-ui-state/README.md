# Expense Tracker in React – Part 1: UI & State

Add expenses with a title, amount, category and date, see the total, and delete items. Everything lives in React state (no backend). Part 2 adds filters, charts and LocalStorage.

📺 **Video:** https://youtu.be/8abONAejIAc (premieres 8 Dec)
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- Planning a bigger project: components + state in one place
- Lifting state up (`ExpenseForm` → `App`)
- Controlled inputs: text, number, select and date
- Form validation with an error message
- `map` with keys, `filter` to delete, `reduce` for the total
- Formatting money with `toLocaleString`

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/expense-tracker-part-1-ui-state
npm install
npm run dev
```
Then open http://localhost:5173
