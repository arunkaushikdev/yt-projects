# Show / Hide Password Toggle in React

A login card with a password field and an eye button that shows or hides the password.

📺 **Video:** https://youtu.be/JRztcJIpZEU · Short: https://youtube.com/shorts/CNPbCSQjQYU
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you'll learn
- Controlled input (`value` + `onChange`)
- Boolean state and toggling it with `!`
- Changing an attribute with a ternary: `type={show ? 'text' : 'password'}`
- `type="button"` inside a form, and `aria-label` for accessibility

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/show-hide-password
npm install
npm run dev
```
Then open http://localhost:5173
