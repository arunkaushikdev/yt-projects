# Expense Tracker in React – Part 2: Filters, Charts & LocalStorage

Builds on [Part 1](../expense-tracker-part-1-ui-state). Filter by month and category, see a bar chart of where your money goes (no chart library), and keep your data after a refresh with LocalStorage.

📺 **Video:** https://youtu.be/45QvAbgqm9k (premieres 11 Dec)
🏠 **All projects:** [Happy Learning HQ – yt-projects](../../README.md)

## What you will learn
- Filtering with `filter` and derived data (no extra state)
- A bar chart with plain CSS and `reduce`
- LocalStorage: lazy `useState` + `useEffect`
- Unique months with `Set`

## Run it locally
```bash
git clone https://github.com/arunkaushikdev/yt-projects.git
cd yt-projects/react/expense-tracker-part-2-filters-charts
npm install
npm run dev
```
Then open http://localhost:5173
